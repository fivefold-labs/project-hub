# Güvenlik

API anahtarı, parola, token, özel anahtar, gerçek kullanıcı verisi ve ham görüşme kayıtları commit edilmez. Örnek yapılandırmalar yalnızca sahte değerler içerir.

Güvenlik açığı veya yanlışlıkla paylaşılmış bir anahtar görürseniz detaylarını genel issue'ya koymadan repo sahibine özel kanaldan iletin. Sızan anahtar önce iptal edilir/yenilenir; commit'i silmek tek başına çözüm değildir.

Ağ ve güvenlik deneyleri sadece ekibin kontrolündeki veya açıkça izin verilen ortamlarda yapılır.
